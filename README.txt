토익스타트 리스닝 단어암기 - 설치형 PWA

구성:
- index.html
- manifest.webmanifest
- sw.js
- vercel.json
- icons/

사용:
1. 이 폴더 전체를 Vercel에 배포합니다.
2. 생성된 HTTPS 주소를 폰에서 엽니다.
3. iPhone: Safari > 공유 > 홈 화면에 추가
4. Android: Chrome > 메뉴 > 앱 설치/홈 화면에 추가

체크 단어, 학습 완료 Day, 마지막 Day와 가리기 모드는 기존과 같은 localStorage 키를 사용하므로
같은 주소에서 업데이트하면 기존 학습 상태가 유지됩니다.
